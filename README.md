# آزمایشگاه علوم | Science Lab

**Science Lab** یک وب‌اپلیکیشن آموزشی فارسی و راست‌به‌چپ برای دانش‌آموزان پایهٔ هشتم است. هدف آن تبدیل مرور علوم به تجربه‌ای مرتب، تعاملی و مناسب موبایل است؛ نسخهٔ فعلی روی دو فصل شیمی کتاب علوم تجربی تمرکز دارد.

**ایدهٔ پروژه:** یک دفتر علوم دیجیتال که خلاصه‌های مفهومی، واژه‌های کلیدی، پرسش‌های تعاملی و پیگیری پیشرفت را در یک رابط یکپارچه جمع می‌کند.

**English description:** An interactive Persian-language study platform for Iranian eighth-grade science. It combines structured lesson notes, highlighted scientific vocabulary, chapter checks, multiple-choice practice, a glossary, and locally saved progress in a responsive right-to-left interface.

## موضوع و محدوده

نسخهٔ فعلی شامل این فصل‌هاست:

1. **مخلوط و جداسازی مواد** — مواد خالص و مخلوط، مخلوط‌های همگن و ناهمگن، محلول‌ها و روش‌های جداسازی.
2. **تغییرهای شیمیایی در خدمت زندگی** — تغییرهای فیزیکی و شیمیایی، نشانه‌های احتمالی واکنش، سوختن و نمونه‌های روزمره.

این پروژه یک ابزار کمک‌آموزشی برای مرور و تمرین است؛ جایگزین کتاب درسی یا راهنمای رسمی معلم نیست.

## قابلیت‌ها

- رابط فارسی با جهت راست‌به‌چپ و فونت Vazirmatn
- صفحهٔ جداگانه برای فصل‌ها و بخش‌های هر درس
- برجسته‌سازی واژه‌ها و مفهوم‌های کلیدی
- پرسش‌های کوتاه در درس و آزمون چندگزینه‌ای
- واژه‌نامهٔ علمی
- داشبورد پیشرفت با ذخیره‌سازی محلی در مرورگر
- ناوبری دسکتاپ و نوار ثابت پایین صفحه در موبایل
- طراحی واکنش‌گرا، نشانگر فوکوس و پشتیبانی از prefers-reduced-motion

## فناوری‌ها

- Next.js App Router
- React 19
- TypeScript
- Tailwind CSS 4 به همراه CSS اختصاصی
- lucide-react
- localStorage برای نگه‌داری پیشرفت در همان مرورگر

## اجرا در رایانه

به Node.js نسخهٔ LTS و npm نیاز دارید:

    npm install
    npm run dev

سپس نشانی http://localhost:3000 را باز کنید.

## بررسی‌های فنی

    npm run lint
    npm run typecheck
    npm run build

این فرمان‌ها برای بررسی کد در نظر گرفته شده‌اند؛ نتیجهٔ موفق آن‌ها فقط پس از اجرا قابل اعلام است.

## ساختار پروژه

- src/app/ — صفحهٔ خانه، فهرست فصل‌ها، درس، تمرین، پیشرفت و ۴۰۴
- src/components/navigation.tsx — ناوبری دسکتاپ و موبایل
- src/content/lessons.ts — داده‌های فصل‌ها، بخش‌ها، واژه‌نامه و پرسش‌ها
- src/content/source-notes.md — سیاست منبع و وضعیت محتوای آموزشی
- docs/PROJECT_BRIEF.md — شرح پروژه، مخاطب و محدوده
- docs/TEXTBOOK_CONTENT_AUDIT.md — چک‌لیست تطبیق محتوا با کتاب درسی

## منبع و دقت آموزشی

منبع موردنظر برای بررسی محتوا، اسکن ۲۰ صفحه‌ای با نام OLOUM.pdf است که بنا بر یادداشت‌های پروژه، فصل اول را در صفحات چاپی ۱ تا ۸ و فصل دوم را در صفحات چاپی ۹ تا ۲۰ پوشش می‌دهد. درگاه رسمی کتاب‌های درسی ایران: https://chap.sch.ir/

**وضعیت دقت محتوا: تطبیق کامل صفحه‌به‌صفحه هنوز تأیید نشده است.** فایل مرجع در این نوبت برای بررسی مستقیم در دسترس نیست و یادداشت منبع موجود در مخزن نیز می‌گوید که پوشش همهٔ فعالیت‌ها، شکل‌ها، پرسش‌ها و یادداشت‌های دست‌نویس هنوز نیاز به بازبینی دارد. بنابراین این مخزن فعلاً ادعای «تطبیق کامل و تأییدشده با کتاب» نمی‌کند. چک‌لیست و معیار پذیرش در گزارش ممیزی محتوا آمده است.

برای اعلام نهاییِ «محتوا با کتاب تطبیق داده شده و تأیید است»، باید همان PDF مرجع دوباره در دسترس باشد، هر دو فصل صفحه‌به‌صفحه بررسی شوند، پرسش‌ها و پاسخ‌ها جداگانه کنترل شوند و نتیجهٔ ممیزی در گزارش ثبت شود. فایل کتاب را به مخزن عمومی اضافه نکنید مگر اینکه مجوز بازنشر آن را داشته باشید.

## استقرار روی Vercel

1. مخزن را به Vercel متصل کنید.
2. Framework Preset را روی Next.js بگذارید.
3. در نسخهٔ فعلی متغیر محیطی الزامی تعریف نشده است.
4. Deploy را اجرا کنید.

## ذخیره‌سازی داده

پیشرفت و نتیجهٔ آزمون فقط در localStorage همان مرورگر ذخیره می‌شود؛ حساب کاربری، پایگاه داده یا همگام‌سازی بین دستگاه‌ها وجود ندارد. اگر ذخیره‌سازی محلی در دسترس نباشد، ممکن است پیشرفت ذخیره نشود، اما بخش‌های آموزشی همچنان قابل استفاده‌اند.
