# آزمایشگاه علوم | Science Lab

وب‌اپلیکیشن فارسی و راست‌به‌چپ برای یادگیری علوم تجربی پایه هشتم، با تمرکز نسخهٔ اول بر فصل‌های «مخلوط و جداسازی مواد» و «تغییرهای شیمیایی در خدمت زندگی».

## فناوری‌ها
- Next.js App Router و React
- TypeScript برای مدل دادهٔ درس و آزمون
- Tailwind CSS 4 به همراه CSS اختصاصی برای کنترل دقیق RTL و واکنش‌گرایی
- فونت Vazirmatn به‌عنوان فونت اصلی فارسی
- lucide-react برای آیکون‌ها
- localStorage برای پیشرفت محلی، بدون حساب کاربری یا بک‌اند

## اجرا در رایانه
به Node.js نسخهٔ LTS و npm نیاز دارید:

```bash
npm install
npm run dev
```

سپس نشانی http://localhost:3000 را باز کنید.

## بررسی‌ها
```bash
npm run lint
npm run typecheck
npm run build
```

## ساختار پروژه
- `src/app/`: صفحهٔ خانه، فهرست فصل‌ها، صفحهٔ درس، تمرین، پیشرفت و صفحهٔ ۴۰۴
- `src/components/navigation.tsx`: ناوبری دسکتاپ و نوار ثابت پایین موبایل
- `src/content/lessons.ts`: داده‌های تایپ‌شدهٔ فصل‌ها، بخش‌ها، واژه‌نامه و پرسش‌ها
- `src/content/source-notes.md`: وضعیت بررسی منبع و سیاست ارجاع صفحات

## RTL و دسترس‌پذیری
جهت سند با `lang="fa"` و `dir="rtl"` تنظیم شده است. ناوبری موبایل بدون منوی همبرگری و با نوار ثابت پایین صفحه است. هدف‌های لمسی، نشانگر فوکوس، بازخورد قابل‌خواندن برای آزمون و پشتیبانی از `prefers-reduced-motion` در نظر گرفته شده‌اند.

## سیاست منبع و دقت آموزشی
منبع رسمی کتاب‌های درسی ایران: https://chap.sch.ir/

**وضعیت منبع:** یک اسکن ۲۰ صفحه‌ای با نام `OLOUM.pdf` از سوی صاحب پروژه در این جلسه ارائه و به‌صورت تصویری بررسی شد. فصل ۱ در صفحات چاپی ۱–۸ و فصل ۲ در صفحات چاپی ۹–۲۰ دیده می‌شوند. این فایل جلد کامل یا شناسنامهٔ نشر ندارد؛ بنابراین سال/ویرایش و رسمی بودن همین فایل تأیید نشده و URL رسمی مستقیمی برای آن در دست نیست. محتوای برنامه هنوز تطبیق کامل صفحه‌به‌صفحه با همهٔ فعالیت‌ها، شکل‌ها و یادداشت‌های دست‌نویس را نگذرانده است. جزئیات و موارد باقی‌مانده در `src/content/source-notes.md` ثبت شده‌اند.

## استقرار روی Vercel
1. مخزن را به Vercel متصل کنید.
2. Framework Preset را روی Next.js بگذارید.
3. هیچ متغیر محیطی لازم نیست.
4. Deploy را اجرا کنید؛ دستور build به‌صورت خودکار اجرا می‌شود.

## ذخیره‌سازی داده
پیشرفت بخش‌ها و نتیجهٔ آزمون فقط در localStorage همان مرورگر ذخیره می‌شود. همگام‌سازی بین دستگاه‌ها وجود ندارد. اگر localStorage در دسترس نباشد، بخش‌های آموزشی و آزمون همچنان قابل استفاده‌اند، اما ذخیره‌سازی در دسترس نخواهد بود.
