# آزمایشگاه علوم | Science Lab

یک وب‌سایت آموزشی فارسی برای یادگیری، تمرین و مرور علوم تجربی پایه هشتم ایران.

**هدف نسخهٔ اول:** آموزش تعاملی فصل‌های ۱ و ۲ با توضیح‌های ساده، مثال‌های روزمره، شکل‌ها و فعالیت‌های کوتاه، واژه‌نامه و آزمون‌های خودسنجی.

## فصل‌ها

1. **مخلوط و جداسازی مواد**
2. **تغییرهای شیمیایی در خدمت زندگی**

محتوا باید با نسخهٔ رسمی کتاب درسی همان سال تحصیلی تطبیق داده شود. منبع رسمی دریافت کتاب‌ها: [پایگاه کتاب‌های درسی سازمان پژوهش و برنامه‌ریزی آموزشی](https://chap.sch.ir/).

## اصول تجربهٔ کاربری

- رابط کاملاً فارسی و راست‌چین (RTL)؛ نه صرفاً متن راست‌چین، بلکه چیدمان، فاصله‌گذاری، آیکون‌ها، فرم‌ها و ترتیب پیمایش نیز مناسب فارسی باشد.
- طراحی ساده، خوانا، آکادمیک و مناسب دانش‌آموزان پایهٔ هشتم.
- در موبایل **هیچ منوی همبرگری وجود نداشته باشد**؛ ناوبری اصلی به‌صورت نوار ثابت پایین صفحه باشد.
- دسترس‌پذیری صفحه‌کلید، کنتراست مناسب، حالت‌های تمرین واضح و بازخورد دوستانه.
- ابتدا بدون حساب کاربری، بک‌اند یا پایگاه داده؛ تا جای ممکن سبک و قابل استقرار روی Vercel.

## فناوری پیشنهادی

- Next.js با App Router
- TypeScript
- Tailwind CSS
- استقرار روی Vercel

## وضعیت

اسکلت اولیهٔ مخزن و شرح پروژه آماده است. رابط و محتوای آموزشی باید بر اساس دستور ساخت موجود در `docs/AI_BUILD_PROMPT.md` پیاده‌سازی شوند.

## اجرای محلی

پس از ساخت برنامهٔ Next.js:

```bash
npm install
npm run dev
```

سپس `http://localhost:3000` را باز کنید.

## دقت علمی و منابع

- نام فصل‌ها، مفاهیم و ترتیب مطالب را از PDF رسمی بررسی کنید؛ به حافظه یا منابع غیررسمی اکتفا نکنید.
- برای هر بخش آموزشی، شمارهٔ صفحهٔ کتاب مرجع را در داده‌های داخلی یا یادداشت‌های توسعه نگه دارید.
- متن درس را با بیان خود و به‌صورت آموزشی بازنویسی کنید؛ صفحات یا بخش‌های طولانی کتاب را عیناً بازنشر نکنید.
- اگر نسخهٔ رسمی قابل دسترسی نبود، این محدودیت را شفاف اعلام کنید و محتوای تأییدنشده را به‌عنوان محتوای رسمی جا نزنید.
